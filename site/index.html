A small, quiet IDE. Terminal, files and editor bound to one project, on your machine or over SSH. Close the window and your shells keep running.

Everything in one window

Open a folder and it anchors the whole window: file tree, shells, editor, language servers and the git branch in the titlebar all follow it. Each command becomes a block you can copy, rerun or hand to the agent, and the gutter shows what changed since your last commit. Switch panes with ⌘1 and ⌘2.

Context

See what your agent will read

Right-click a project to see what a Claude Code session started there will load: memory, the CLAUDE.md chain, skills, hooks and MCP servers. Each row is the real file on the machine that owns the project, and ↵ opens it in the editor.

Drawings

Diagrams open as diagrams

Excalidraw files open as the drawing, themed to match the app and saved like any other file, with the JSON one toggle away. When Claude edits one, you watch it change. BPMN, notebooks, images, SVG, HTML and Markdown preview too.

Remote works like local

Connect a server once, and a project there behaves just like one on your laptop.

Stays connected

A small helper runs on the server, verified against a checksum built into the app. Sleep, switch networks, reconnect: nothing in flight is lost.

Shells that survive

Remote terminals run in tmux on the host, so they keep their jobs across restarts and still work if the helper is down. Ports that start listening are forwarded to your machine, ready to open.

Clear when it breaks

It retries on its own first, then tells you what to do next: retry, reinstall, or open a terminal on the host. Works with Linux x86_64 and aarch64 hosts, and Apple silicon Macs.

Works with the agent you already use

Claude Code runs in its own TUI, in an ordinary terminal tab. Your subscription works because it's just claude, and term.hut never touches your login. It won't answer the agent's prompts or ping you about it. It shows you what changed.

⌘⇧Y

Review what the agent changed, turn by turn

Every hunk is grouped under the prompt that produced it. Undo, stage or keep each one without leaving the keyboard. It updates while the agent is still working, locally or over SSH, and it never undoes a change it can't trace to the agent.

⌘⇧N

Start an agent here or on a server

Pick a project, write a prompt, choose the model and effort, and run it now or on a schedule. The dialog shows the exact command it runs, so you can do the same thing from any shell.

Unattended

Runs overnight, no app required

The same command works from cron on the host. The agent keeps running after the shell exits, and in the morning you review its changes like any other agent's, from that machine or another.

crontab
# every morning at 05:30, on the machine with the repo
30 5 * * *  th agent run --cwd ~/work/api \
              --prompt-file ~/prompts/nightly-triage.md \
              --permission-mode acceptEdits

Why I built it

I kept losing track of what was running where: a few repos, a few agents, a few servers. I tried the other apps, and each had a limit I couldn't live with. VSCodium with Claude Code was what I actually used, but it was far more than I needed.

So term.hut started as a question: could I build something small that keeps only the parts I find useful, and learn Rust and Tauri along the way? It's how I work now, for my business and my own projects. I keep it current with Claude Code so new features work and nothing breaks.

It reuses rather than remakes. The agent is Claude Code's own TUI, the shells are tmux, and the scheduler is cron. I build for the machines I use, and I'd rather it stay small than take over the world.
